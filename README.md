# Hydraulic System Valve Condition Prediction

Machine Learning project for predicting whether the valve condition
of a hydraulic system is optimal or non-optimal.

## Project Structure

- `project_ml.ipynb` : complete data analysis and machine learning workflow
- `data/` : project datasets
- `models/` : trained model files
- `app/` : web application
- `tests/` : unit tests
- `Dockerfile` : container configuration
